# Address Book Management System in C

## About the Project
The Address Book Management System is a console-based application developed using C programming. It allows users to manage contact details efficiently.

## Features
- Add new contacts
- Search for contacts
- Edit existing contacts
- Delete contacts
- Store contact information using file handling

## Technologies Used
- C Programming
- Structures and Functions
- File Handling
- GCC Compiler

## Project Files
- `main.c` - Main program
- `contact.c` - Contact management functions
- `contact.h` - Contact function declarations
- `file.c` - File handling operations
- `file.h` - File handling declarations
- `contacts.txt` - Contact data storage

## How to Compile and Run

Compile the project using GCC:

```bash
gcc main.c contact.c file.c -o AddressBook
```

Run the application:

```bash
./AddressBook
```
